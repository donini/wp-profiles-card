How to use CardPress

Use the studio, or make a card directly with a URL.

A card wherever you need it

The card endpoint returns an SVG image with an embedded avatar. You can use it in an image tag, a Markdown file, or download it.

/card?username=rodrigodonini

Use it in your GitHub README

The studio generates Markdown with all of your choices included. A profile link inside an SVG may only be clickable when the SVG is opened directly; the Markdown wrapper makes the whole image a link.

Use the profile data

The JSON endpoint supports cross-origin requests and keeps the original field names: userName, name, avatar, memberSince, and badges.

/json?username=rodrigodonini

Keeping cards current

Profiles are cached for 24 hours. Use refresh=true to request a refresh; requests within one minute of the last successful fetch reuse that data. Image clients may cache cards for five minutes. During a temporary WordPress.org outage, an existing cached card remains available.

About the community list

The community page credits all contributors reported by the project’s GitHub repository. Below them, the profile directory lists WordPress.org profiles requested through this CardPress installation. No visitor IP addresses or request history are stored.

Something missing?

Badges come from public WordPress.org profile pages. Changes to that site's markup can affect extraction. Unknown badge icons receive a fallback so the rest of the card still renders.
